# She Can Foundation

Website and lightweight Express backend for the She Can Foundation.

## Project Structure

- `index.html`, `our-story.html`, `certificate.html`, `gallery.html`, `donate.html` - site pages
- `assets/css/` - stylesheets
- `assets/js/` - browser scripts
- `assets/images/` - site images and media assets
- `data/` - local runtime data generated by the server
- `scripts/` - utility scripts used while building and polishing the site
- `server.js` - Express server and API routes

## Run Locally

```bash
npm install
npm start
```

The app runs at `http://localhost:3001` by default.
